# 台本（スピーカーノート）の書き方

このスキルでは **全スライドに台本を付ける**。台本は `deck.script(slide, "…")`
でスピーカーノートとして埋め込む（スライド面には出さない）。台本は「読み上げ
原稿」ではなく「実際に口で話すときのガイド」。

## 基本方針

- **スライドの文字をそのまま繰り返さない。** スライドは要点、台本は“その背景・
  理由・含意・つなぎ”を補う。聞き手はスライドを読めるので、口頭では肉付けする。
- **1枚 30〜60秒で話せる量**（おおむね 100〜200字程度）。長すぎると棒読みになる。
- **話し言葉で書く。** 「〜です/ます」。箇条書きではなく、そのまま声に出せる文。
- **つなぎを入れる。** 各ページ冒頭に前ページからの接続（「ここまでが現状です。
  では—」）を一言入れると流れが切れない。
- **数字には必ず出典・解釈を添える。** 「12%という数字は△△調査ベースで、これは
  □□を意味します」のように、数字の“意味”を言う。
- **想定問答（任意）。** 突っ込まれやすい点は「もし〜と聞かれたら、〜と返す」を
  末尾に短く添えてよい。

## 構成テンプレ（1ページぶん）

```
［つなぎ］前ページからの一言接続
［主張］このページで一番言いたいこと（タイトルの結論を口語で）
［根拠/具体］数字・事例・理由を1〜2点
［含意/次へ］だから何が言えるか、次にどうつなぐか
（必要なら）［想定問答］聞かれたら〜と返す
```

## 例

**表紙**
> 本日はお時間をいただきありがとうございます。戦略企画部の山田です。これから約
> 20分で、新規事業の市場参入について、なぜ今なのか・どう勝つのかをご説明します。
> 結論から申し上げると、参入の好機は今後2〜3年に絞られる、というのが本日の主張です。

**統計ページ（市場規模）**
> まず市場の大きさです。注目いただきたい数字は3つ。市場は5年で1.8倍、年率では12%
> の成長です。これは△△調査をベースにした保守的な見立てで、上振れ余地もあります。
> 2030年には3,200億円規模になる見込みで、つまり“今動けば取りに行ける”市場だと言えます。

**章扉**
> ここまでが市場環境でした。次に、その市場で我々がどう戦うか、競争戦略に話を移します。

## やってはいけない

- スライドの箇条書きをそのまま音読する台本（情報が増えていない）。
- 1ページに数百字以上の長文（読み切れず聞き手も置いていかれる）。
- 台本を空にする／一部ページだけ付ける（**全ページ必須**）。
