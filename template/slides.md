# スキルの実体は、説明文と手順を書いた Markdown ファイルである

```markdown
---
name: internal-slides
description: 社内共有向けの Slidev スライドを書く・直す・レビューするときに使う。
  見出し＝主張・絵文字禁止・禁止語・数字の出典などのルールを lint で検査しながら進める。
---

# 社内共有スライドを書く

## 手順
1. 資料のブランチにいるか確かめる
2. 見出し＝主張の一文だけを先に並べて、筋を確かめる
3. 本文を書く。数字には出典を置く
4. npm run lint:slides を実行し、error を 0 にする
```

<!--
この資料を作るのに実際に使っているスキル（.claude/skills/internal-slides/SKILL.md）を短くしたもの。
上の --- で囲んだ部分が説明文（YAML）、下が本文（Markdown）。
AIは description を読んで「今このスキルを使うか」を判断する。
-->
